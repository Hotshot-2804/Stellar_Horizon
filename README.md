# Stellar Horizon

An endless 2D space survival shooter built from scratch in the Godot Engine. Navigate a dangerous asteroid field as the speed and difficulty dynamically scale the longer you stay alive.

## 🚀 Play the Game
Download the latest Windows and macOS builds on my [https://hotshot-2804.itch.io/stellar-horizon]

## 🛠️ Technical Features
* **Persistent Leaderboard:** Engineered with a local SQLite database (`godot-sqlite`) to permanently track and save high scores across sessions, safely mapped to the OS-approved `user://` path.
* **Dynamic Difficulty:** Utilizes a custom mathematical scaling system that accelerates obstacle generation and velocity as the player's score increases.
* **Platform Packaging:** Configured with native macOS dynamic library validation entitlements and cross-platform export profiles.

## 🕹️ Built With
* **Engine:** Godot 4 (GDScript)
* **Database:** SQLite
